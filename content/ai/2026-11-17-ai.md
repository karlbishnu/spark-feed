알리바바(Alibaba Cloud)가 독자 개발한 플래그십 비전-언어 모델(VLM) 'Qwen2.5-VL-72B-Instruct'를 오픈소스로 전격 공개했습니다. 이전 세대인 Qwen2-VL의 성공에 이어 출시된 Qwen2.5-VL 제품군은 대규모 사전학습 데이터와 구조적 최적화를 바탕으로 상용 폐쇄형 멀티모달 모델인 GPT-4o, Claude 3.5 Sonnet과 대등하거나 일부 벤치마크에서 능가하는 시각 추론 및 에이전트 성능을 제시합니다.

---

### 1. 핵심 아키텍처 및 기술 혁신

- **동적 해상도 및 비디오 프레임 레이트 학습**: 시간 축 차원에 동적 FPS 샘플링을 적용하여 모델이 가변 샘플링 레이트의 1시간 이상 장편 영상을 자연스럽게 분석합니다.
- **시간 축 정렬 mRoPE (Multimodal Rotary Position Embedding)**: 절대 시간 정렬과 ID를 타임라인 축에 결합하여 영상 내 특정 사건 발생 구간을 초 단위(Sub-second)로 정밀하게 핀포인트 로컬라이징할 수 있습니다.
- **고효율 윈도우 어텐션 ViT**: Vision Transformer(ViT) 인코더에 윈도우 어텐션을 전략적으로 결합하여 학습 및 추론 속도를 대폭 개선했습니다.
- **비주얼 에이전트 및 구조화 출력**: 컴퓨터 GUI 및 모바일 화면 조작(ScreenSpot)을 직접 수행하며, 인보이스, 영수증, 표 등 복잡한 문서 이미지를 정밀한 JSON 및 HTML 포맷으로 변환합니다.

### 3. 주요 벤치마크 평가 결과

Qwen2.5-VL-72B-Instruct는 다분야 시각 추론, 고난도 문서 파싱, 멀티모달 수학 문제 해결에서 오픈소스 진영 최고 수준의 점수를 기록했습니다.

- **DocVQA (문서 이해)**: 96.4% (복잡한 양식, 영수증, 비정형 표 데이터 파싱)
- **MathVista (testmini, CoT)**: 74.8% ~ 78.2% (시각 수학 추론 오픈 모델 1위 수준)
- **MMBench-EN**: 86.5% (종합 시각 언어 질의응답)
- **ChartQA**: 88.96% (차트 및 그래프 정밀 데이터 해석)
- **EgoSchema / VideoMME**: 비디오 시간 추론 및 장문맥 분석 지표에서 SOTA 기록

### 4. 로컬 구동(Ollama / GGUF) 지원 여부

Qwen2.5-VL 시리즈는 공개 즉시 허깅페이스 트랜스포머스(Transformers), vLLM, SGLang 생태계와 함께 Ollama의 정식 라이브러리에 등록되었습니다. 

- **Ollama CLI 명령**:
  ```bash
  # 72B 플래그십 모델 구동
  ollama run qwen2.5vl:72b

  # 로컬 VRAM 환경에 맞춘 경량 라인업 구동 (7B / 3B)
  ollama run qwen2.5vl:7b
  ollama run qwen2.5vl:3b
  ```
  *(참고: Ollama 0.7.0 이상 버전이 권장되며, 72B 4-bit 양자화 모델은 약 48GB~71GB 수준의 비디오 메모리 환경 또는 다중 GPU 환경에서 원활하게 동작합니다.)*

- **GGUF 및 양자화 지원**:
  Unsloth 및 llama.cpp 커뮤니티를 통해 Q4_K_M, Q8_0, AWQ 양자화 포맷이 함께 배포되어 로컬 AI 에이전트 및 고성능 온프레미스 파이프라인 구축에 즉시 투입할 수 있습니다.
