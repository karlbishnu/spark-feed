딥시크(DeepSeek)가 복잡한 수학, 코딩, 논리 추론 분야에서 상용 프론티어 모델과 대등한 성능을 제공하는 오픈 가중치 대형 추론 모델 **DeepSeek-R1**과 기초 연구 모델인 **DeepSeek-R1-Zero**를 전격 공개했습니다. 전체 가중치는 완전한 상업적 이용 및 수정이 허용되는 MIT 라이선스로 배포되었습니다.

### 1. 모델 스펙 및 아키텍처 특징
* **총 파라미터 수**: 671B (토큰 생성 시 활성화 파라미터는 37B 수준의 MoE 구조)
* **컨텍스트 윈도우**: 최대 128K 토큰 지원 (장문 독해 및 복잡한 다단계 논리 전개 최적화)
* **기반 아키텍처**: DeepSeek-V3-Base 기반, MLA(Multi-head Latent Attention) 및 DeepSeekMoE 아키텍처 채택
* **학습 방식**: 방대한 지도 학습 데이터셋(SFT) 의존도를 대폭 낮추고, 대규모 강화학습(RL, Group Relative Policy Optimization - GRPO)을 적용하여 스스로 사고 과정(Chain of Thought)을 검증·수정하는 자기 성찰(Self-reflection) 메커니즘 구축

### 2. 주요 벤치마크 평가 결과
DeepSeek-R1은 고난도 경시대회급 수학 및 코딩 벤치마크에서 기존 오픈소스 모델들을 크게 상회하며 독점 추론 모델(OpenAI o1)에 필적하는 지표를 기록했습니다.

* **AIME 2024 (미국 수학 초청 경시대회)**: Pass@1 기준 **79.8%** 달성 (Consensus 64 샘플 기준 90% 이상 도달)
* **MATH-500**: 정확도 **97.3%** 달성
* **GPQA Diamond**: 대학원 수준 고난도 과학 추론 패스율 **71.5%** 기록
* **MMLU (다분야 지식 이해)**: **90.8%** 달성
* **Codeforces**: 퍼센타일 **96.3%** 기록 (경쟁 프로그래밍 부문 인간 상위 4% 수준)

### 3. 로컬 구동 및 온프레미스 인프라 지원
경량화 인퍼런스 생태계 및 로컬 AI 프레임워크와의 호환성을 완벽히 갖추고 있습니다.

* **Ollama 로컬 구동**: 
  * 원본 MoE 모델 구동:
    ```bash
    ollama run deepseek-r1:671b
    ```
  * 로컬 환경(PC/맥북/엣지 디바이스)을 위한 공식 증류(Distilled) 모델 지원:
    ```bash
    ollama run deepseek-r1:1.5b
    ollama run deepseek-r1:7b
    ollama run deepseek-r1:8b
    ollama run deepseek-r1:14b
    ollama run deepseek-r1:32b
    ollama run deepseek-r1:70b
    ```
* **엔터프라이즈 서빙 엔진**: vLLM 및 SGLang 프레임워크에서 MoE 텐서 병렬화(TP)와 FP8 양자화를 기본 지원하여 멀티 GPU 클러스터 기반 고속 서빙이 가능합니다.
* **GGUF 양자화**: llama.cpp 및 LM Studio를 통해 1.58비트/4비트 양자화 포맷(Q4_K_M 등) 가중치가 허브에 등록되어 메모리 제약 환경에서도 로컬 실행이 가능합니다.
