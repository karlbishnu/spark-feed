딥시크(DeepSeek)가 복잡한 수학, 코딩 및 논리적 추론(Reasoning)에 특화된 차세대 오픈 가중치 언어모델 **DeepSeek-R1**과 연구용 프로토타입 **DeepSeek-R1-Zero**를 공식 출시하고 가중치를 Hugging Face에 공개했습니다. 이번 릴리즈는 대규모 강화학습(RL)을 기반으로 자가 검증 및 장문 사고 과정(Chain-of-Thought, CoT)을 자율적으로 형성하도록 설계되었으며, 상용 비공개 모델인 OpenAI o1에 필적하는 추론 성능을 상업적 이용이 가능한 MIT 라이선스로 개방한 점이 특징입니다.

---

### 1. 모델 핵심 스펙 및 아키텍처

- **기반 아키텍처**: DeepSeek-V3-Base 기반 Mixture-of-Experts (MoE) 구조
- **총 파라미터 수**: 총 671B(6,710억 개), 토큰당 활성 파라미터 37B
- **컨텍스트 윈도우**: 최대 128K (128,000 토큰) 지원 (단일 턴 생성 제한: 최대 32,768 토큰)
- **학습 방법론**: 사전 지도학습 미세조정(SFT) 없이 대규모 순수 강화학습으로 추론 능력을 유도한 R1-Zero를 거쳐, 가독성 향상과 다국어 혼용 방지를 위한 소량의 콜드 스타트 데이터를 결합한 2단계 파이프라인 적용
- **라이선스**: MIT License (상업적 이용, 수정, 재배포 및 지식 증류 학습 허용)

---

### 2. 주요 벤치마크 성능 평가

DeepSeek-R1은 고난도 수학 및 알고리즘 경진대회 평가에서 기존 플래그십 오픈 모델을 크게 앞지르며, 프론티어급 폐쇄형 추론 모델과 대등한 점수를 기록했습니다.

- **MATH-500**: **97.3%** 달성 (OpenAI o1의 96.4%와 대등)
- **AIME 2024 (pass@1)**: **79.8%** (Consensus 64 설정 시 86.7%)
- **MMLU**: **90.8%**
- **MMLU-Pro**: **84.0%**
- **GPQA Diamond**: **71.5%**
- **Codeforces**: 백분위수 **96.3%** (레이팅 2,029 달성)

### 3. 경량 추론 증류(Distillation) 모델군

DeepSeek 연구진은 671B 풀사이즈 모델의 CoT 추론 데이터를 활용하여 오픈소스 소형 모델에 직접 증류한 **DeepSeek-R1-Distill** 시리즈 6종을 동시에 배포했습니다.

1. **DeepSeek-R1-Distill-Qwen (1.5B, 7B, 14B, 32B)**
   - Qwen2.5 시리즈 기반 파인튜닝
   - 32B 증류 모델의 경우 MATH-500 94.3%, AIME 2024 72.6%를 기록하며 중소형 단일 GPU 환경에서도 플래그십급 수학 추론 능력을 발휘
2. **DeepSeek-R1-Distill-Llama (8B, 70B)**
   - Llama 3/3.1 아키텍처 기반 파인튜닝
   - 70B 모델은 MATH-500 94.5%, AIME 2024 70.0% 기록

### 4. 로컬 구동 및 런타임(Ollama/vLLM) 지원

로컬 및 온프레미스 인프라 환경에서 즉시 배포할 수 있도록 공식 생태계 연동이 완료되었습니다.

- **Ollama 공식 등록**:
  - 초경량 및 중형 증류 모델 로컬 실행:
    ```bash
    ollama run deepseek-r1:1.5b
    ollama run deepseek-r1:7b
    ollama run deepseek-r1:8b
    ollama run deepseek-r1:14b
    ollama run deepseek-r1:32b
    ollama run deepseek-r1:70b
    ```
  - 풀사이즈 양자화 모델:
    ```bash
    ollama run deepseek-r1:671b
    ```
- **vLLM 및 SGLang 서빙**:
  - FP8 네이티브 양자화 가중치 지원으로 멀티 GPU 노드(8×H100/H200/A100) 환경에서 분산 텐서 병렬화 서빙 가능
  - 권장 추론 파라미터: 온도(Temperature) 0.5 ≈ 0.7 (권장값 0.6), 시스템 프롬프트 배제 권장 (사용자 프롬프트 내에 모든 사고 유도 지침 포함 권장)
