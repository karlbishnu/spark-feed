인공지능 연구소 딥시크(DeepSeek-AI)가 고난도 수학, 코딩, 복합 논리 추론 분야에서 상용 폐쇄형 플래그십 추론 모델(OpenAI o1 등)과 대등하거나 이를 상회하는 오픈 가중치 추론 LLM인 **'DeepSeek-R1'**을 정식 공개했습니다. 대규모 강화학습(RL)을 통해 자가 검증(Self-Verification) 및 장기적 사고의 사슬(Long Chain-of-Thought) 능력을 유도한 이 모델은, 파라미터 전체 가중치와 소형 고효율 증류(Distilled) 모델 라인업, 추론 파이프라인 코드 전체를 상업적 이용이 가능한 MIT 라이선스로 배포했습니다.

---

### 1. 모델 아키텍처 및 핵심 스펙

* **기반 아키텍처**: DeepSeek-V3 기반의 희소 혼합 전문가(Sparse Mixture-of-Experts, MoE) 구조 채택
* **총 파라미터 수 (Total Parameters)**: 671B (약 6,710억 개)
* **토큰당 활성화 파라미터 (Activated Parameters)**: 토큰 1개당 37B 활성화 (고효율 연산 및 처리 속도 최적화)
* **컨텍스트 길이 (Context Window)**: 최대 128K (131,072 토큰)
* **핵심 학습 메커니즘**:
  * 사전 지도학습(SFT) 데이터셋 없이 대규모 강화학습만으로 모델 스스로 사고 과정을 탐색하고 반성하는 역량을 검증한 'DeepSeek-R1-Zero' 연구 성과를 결합.
  * 다단계 파이프라인(소량의 콜드스타트 데이터 → 대규모 RL 단계 → 거부 샘플링 및 새로운 SFT → 인간 선호도 정렬 RL)을 거쳐 가독성과 언어 일관성이 대폭 개선된 다단계 사고 프로세스 확립.
* **라이선스**: MIT License (가중치 및 코드의 상업적 활용, 수정, 증류 학습 전면 허용)

### 2. 주요 벤치마크 평가 결과

DeepSeek-R1은 복합 추론 및 수학, 프로그래밍 경시대회 수준의 난이도 평가에서 세계 정상급의 지표를 기록했습니다.

| 평가 벤치마크 | DeepSeek-R1 | OpenAI o1-1217 | Claude 3.5 Sonnet (1022) |
| :--- | :---: | :---: | :---: |
| **AIME 2024 (Pass@1)** | **79.8%** | 79.2% | 16.0% |
| **MATH-500 (Pass@1)** | **97.3%** | 96.4% | 78.3% |
| **MMLU (Pass@1)** | **90.8%** | 91.8% | 88.3% |
| **MMLU-Pro (EM)** | **84.0%** | 80.0% | 78.0% |
| **GPQA Diamond (Pass@1)** | **71.5%** | 75.7% | 65.0% |
| **Codeforces (Rating)** | **2,029** (상위 96.3%) | 2,061 | 717 |
| **LiveCodeBench (Pass@1)** | **65.9%** | 63.4% | 38.9% |
| **SWE-bench Verified (Resolved)** | **49.2%** | 48.9% | 49.0% |

*수학 올림피아드 벤치마크인 AIME 2024에서 79.8%를 기록해 오픈 가중치 모델 역사상 최초로 독점 상용 추론 모델을 넘어섰으며, MATH-500에서도 97.3%라는 압도적인 정답률을 확보했습니다.*

### 3. 고효율 증류 모델 (Distilled Models) 라인업 동시 공개

연구팀은 DeepSeek-R1의 추론 패턴 데이터를 오픈소스 베이스 모델(Qwen 2.5 및 Llama 3)에 파인튜닝한 경량 증류 모델 6종을 함께 공개했습니다.

* **DeepSeek-R1-Distill-Qwen-1.5B / 7B / 14B / 32B**
* **DeepSeek-R1-Distill-Llama-8B / 70B**
* **증류 모델 주요 성과**:
  * **DeepSeek-R1-Distill-Qwen-32B**: AIME 2024 72.6%, MATH-500 94.3%를 달성하여 OpenAI o1-mini(AIME 63.6%)를 현격한 격차로 추월.
  * **DeepSeek-R1-Distill-Qwen-7B**: MATH-500에서 92.8%, AIME 2024 55.5%를 달성하여 엣지 디바이스에서도 고난도 추론 수행 가능.

### 4. 로컬 구동 환경 및 Ollama 지원

DeepSeek-R1 패밀리는 Ollama, vLLM, SGLang, LMDeploy 등 주요 로컬 및 서빙 프레임워크에 즉시 연동됩니다.

#### Ollama 원클릭 로컬 실행
Ollama를 통해 플래그십 671B 모델뿐만 아니라 하드웨어 사양에 맞춘 다양한 증류 모델을 단일 명령어로 즉시 로컬 실행할 수 있습니다:

```bash
# 기본 경량화 모델 구동 (단일 GPU 및 노트북 환경)
ollama run deepseek-r1

# 크기별 증류 모델 실행
ollama run deepseek-r1:1.5b
ollama run deepseek-r1:7b
ollama run deepseek-r1:8b
ollama run deepseek-r1:14b
ollama run deepseek-r1:32b
ollama run deepseek-r1:70b

# 671B 원본 MoE 모델 구동 (멀티 GPU 및 대규모 서버 환경)
ollama run deepseek-r1:671b
```

#### 배포 및 프롬프트 권장 설정
* **하이퍼파라미터**: 반복 현상 방지 및 논리적 다각도 탐색을 위해 Temperature는 0.5 ~ 0.7 범위(기본 0.6 권장) 설정을 권장합니다.
* **프롬프트 템플릿**: 시스템 프롬프트(System Prompt)는 가급적 생략하고, 추론에 필요한 조건과 요구사항을 유저 프롬프트(User Prompt) 본문에 직접 기술하는 방식이 가장 정교한 CoT 추론 결과를 유도합니다.
