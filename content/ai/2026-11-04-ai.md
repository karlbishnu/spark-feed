중국의 오픈소스 인공지능 연구소 딥시크(DeepSeek)가 복잡한 수학, 코딩, 과학적 추론 문제를 단계별 사고 체계(Chain-of-Thought)로 해결하는 차세대 대규모 언어 모델 'DeepSeek-R1'과 순수 강화학습(RL) 기반의 전구체인 'DeepSeek-R1-Zero'의 가중치를 허깅페이스(Hugging Face)를 통해 전면 오픈소스로 공개했습니다. 아울러 연구진은 상업적 이용 및 연구 목적의 제약이 거의 없는 MIT 라이선스를 적용하고, 대형 모델의 추론 능력을 중소형 오픈소스 LLM에 전이한 'DeepSeek-R1-Distill' 6종 모델을 함께 배포했습니다.

### 1. 모델 핵심 스펙 및 아키텍처

- **총 파라미터 수**: 671B (6,710억 개) MoE (Mixture-of-Experts) 구조
- **토큰당 활성화 파라미터**: 토큰당 약 37B (370억 개) 활성화
- **컨텍스트 윈도우**: 128K 토큰 지원 (장문 맥락 인식 및 다단계 사고 전개 최적화)
- **학습 아키텍처 및 방법론**: DeepSeek-V3 베이스 모델을 기반으로 대규모 콜드 스타트 데이터와 다단계 강화학습 파이프라인(GRPO; Group Relative Policy Optimization)을 결합했습니다. 지도 학습(SFT) 없이 대규모 RL만으로 자기 성찰 및 검증 행동을 유도하는 능력을 입증했으며, 가독성 향상과 환각 억제를 위한 후속 정렬 단계를 거쳤습니다.
- **라이선스**: MIT License (연구 및 상업적 목적 전면 무료 개방)

### 2. 주요 벤치마크 평가 결과

DeepSeek-R1은 수학, 코딩, 범용 고난도 지식 평가 전반에서 폐쇄형 최고 성능 추론 모델인 OpenAI o1-1217에 필적하거나 이를 넘어서는 성능 지표를 기록했습니다.

- **AIME 2024 (Pass@1)**: 79.8% (OpenAI o1-1217의 79.2%를 상회하며 미국 수학 초청 시험 수준의 난제를 돌파)
- **MATH-500 (Pass@1)**: 97.3% (o1-1217의 96.4% 대비 우세)
- **MMLU (Pass@1)**: 90.8% (범용 지식 및 대학 수준 이해도 측정)
- **MMLU-Pro (Pass@1)**: 84.0%
- **GPQA Diamond (Pass@1)**: 71.5% (박사급 생물·물리·화학 추론 문제)
- **Codeforces**: Elo 레이팅 2,029점 및 96.3 백분위수(Percentile) 달성 (인간 경쟁 프로그래밍 상위 3.7% 수준)
- **SWE-bench Verified**: 49.2% (실제 깃허브 소프트웨어 엔지니어링 이슈 해결 능력 검증)

### 3. 소형 모델 증류(Distillation) 및 로컬 구동(Ollama 등) 환경

딥시크는 671B 초거대 본체 모델의 막대한 인프라 부담을 해소하기 위해 DeepSeek-R1이 생성한 80만 개의 추론 궤적 데이터를 Qwen2.5 및 Llama-3 시리즈에 증류 학습시킨 소형 모델 6종을 동시에 제공합니다. 

- **증류 모델 라인업**:
  - `DeepSeek-R1-Distill-Qwen-1.5B`
  - `DeepSeek-R1-Distill-Qwen-7B`
  - `DeepSeek-R1-Distill-Llama-8B`
  - `DeepSeek-R1-Distill-Qwen-14B`
  - `DeepSeek-R1-Distill-Qwen-32B`
  - `DeepSeek-R1-Distill-Llama-70B`
- **로컬 구동 지원**:
  - **Ollama**: 공식 레지스트리에 등록되어 단일 CLI 명령어로 즉각 실행이 가능합니다.
    - `ollama run deepseek-r1` (기본 7B 경량 모델)
    - `ollama run deepseek-r1:1.5b`, `ollama run deepseek-r1:14b`, `ollama run deepseek-r1:32b`, `ollama run deepseek-r1:70b`, `ollama run deepseek-r1:671b` 등 파라미터별 세부 태그 지원
  - **추론 엔진 호환**: vLLM, SGLang, llama.cpp, Unsloth, LM Studio 등 주요 오픈소스 추론 프레임워크에서 FP8, 4비트 양자화(GGUF, AWQ, EXL2) 형태로 완벽하게 구동 가능합니다. 1.5B~8B 모델의 경우 M 시리즈 맥북 및 일반 컨슈머용 단일 GPU(RTX 3060/4060 이상) 환경에서도 원활한 온디바이스 실시간 추론을 보장합니다.
