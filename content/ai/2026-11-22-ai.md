## 1. 개요 및 모델 소개
딥시크(DeepSeek)가 복합 수학, 코딩, 다단계 논리 추론 분야에서 OpenAI의 추론 모델 o1과 대등한 성능을 발휘하는 차세대 오픈 웨이트 모델 **'DeepSeek-R1'** 및 연구 프로토타입 **'DeepSeek-R1-Zero'**를 허깅페이스(Hugging Face)와 깃허브에 공식 공개했습니다. 

DeepSeek-R1은 지도 학습 미세조정(SFT) 데이터에 전적으로 의존하던 기존 LLM 개발 패러다임에서 벗어나, 대규모 강화학습(Large-scale Reinforcement Learning)만을 활용해 자가 검증(Self-verification), 반성적 사고(Reflection), 심층 연쇄 추론(Long Chain-of-Thought)을 자발적으로 유도해 낸 오픈소스 혁신 모델입니다. 상업적 이용과 수정·배포가 자유로운 MIT 라이선스를 채택해 글로벌 오픈소스 AI 생태계에 큰 반향을 일으키고 있습니다.

---

## 2. 모델 아키텍처 및 하드웨어 스펙
DeepSeek-R1은 고효율 희소 혼합 전문가(Sparse Mixture-of-Experts, MoE) 구조인 DeepSeek-V3-Base를 기반으로 사후 학습(Post-training)을 거쳐 설계되었습니다.

- **총 파라미터 수**: 671B (6,710억 개)
- **토큰당 활성화 파라미터 수**: 37B (370억 개)
- **컨텍스트 윈도우(Context Window)**: 기본 128K 토큰 (최대 128,000 토큰 지원)
- **최대 단일 출력 토큰(Max Generation Length)**: 최대 32,768 ~ 64,000 토큰
- **어텐션 메커니즘**: MLA(Multi-Head Latent Attention) 기술을 적용해 KV 캐시 메모리 점유율을 대폭 절감하고 대규모 동시 추론 효율을 극대화
- **라이선스**: MIT License (완전 오픈 웨이트, 상업적 활용 및 연구 배포 자유)

## 3. 공인 벤치마크 평가 결과
DeepSeek-R1은 복합 수학 경시대회 문제와 전문 코딩 평가 지표에서 오픈소스 모델 역대 최고점을 경신했으며, 폐쇄형 플래그십 추론 모델인 OpenAI o1에 육박하거나 일부 항목에서 앞서는 결과를 기록했습니다.

### 주요 세부 벤치마크 지표 (Pass@1 기준)
- **AIME 2024 (미국 수학 초청 경시대회)**: **79.8%** 달성 (OpenAI o1-1217의 79.2%를 능가, 다수결 샘플링 cons@64 적용 시 90% 상회)
- **MATH-500**: **97.3%** 달성 (OpenAI o1-1217의 96.4% 대비 우세)
- **GPQA Diamond (박사급 생물·물리·화학 추론)**: **71.5%**
- **MMLU (다분야 학술 지식)**: **90.8%** (MMLU-Redux: 92.9%, MMLU-Pro: 84.0%)
- **Codeforces (알고리즘 코딩 랭킹)**: 평점 **2,029점** 획득 (전체 인간 경쟁 참가자의 상위 96.3% 수준)
- **LiveCodeBench (Pass@1-COT)**: **65.9%** 달성
- **SWE-bench Verified (소프트웨어 엔지니어링 이슈 해결)**: **49.2%** 해결률 기록

## 4. 증류(Distillation) 모델 제품군
연구실이나 단일 GPU 환경을 보유한 일반 개발자를 위해 DeepSeek-R1의 추론 데이터를 기반으로 증류(Distillation)된 고효율 오픈 경량 모델 6종도 함께 출시되었습니다.

- **Qwen 기반 증류 모델**: 
  - `DeepSeek-R1-Distill-Qwen-1.5B`
  - `DeepSeek-R1-Distill-Qwen-7B`
  - `DeepSeek-R1-Distill-Qwen-14B` (AIME 2024 69.7%, 단일 16GB GPU에서 구동 적합)
  - `DeepSeek-R1-Distill-Qwen-32B` (AIME 2024 72.6%, MATH-500 94.3%로 OpenAI o1-mini를 전반적으로 압도)
- **Llama 기반 증류 모델**:
  - `DeepSeek-R1-Distill-Llama-8B`
  - `DeepSeek-R1-Distill-Llama-70B`

## 5. 로컬 구동(Ollama 등) 및 배포 생태계 지원 여부
DeepSeek-R1 제품군은 공개 즉시 전 세계 로컬 LLM 추론 프레임워크와 양자화 에코시스템에 전면 편입되었습니다.

- **Ollama 공식 완벽 지원**:
  - 로컬 터미널에서 단일 명령어로 즉시 다운로드 및 실행이 가능합니다.
  - 대용량 풀 모델: `ollama run deepseek-r1:671b`
  - 소비자용 하드웨어용 증류 모델: `ollama run deepseek-r1:1.5b`, `ollama run deepseek-r1:7b`, `ollama run deepseek-r1:8b`, `ollama run deepseek-r1:14b`, `ollama run deepseek-r1:32b`, `ollama run deepseek-r1:70b`
- **vLLM 및 SGLang 프레임워크**:
  - vLLM 및 SGLang 최신 릴리즈에서 DeepSeek-R1 아키텍처에 대한 텐서 병렬화(Tensor Parallelism) 및 FP8 서빙을 네이티브로 지원합니다.
- **Llama.cpp 및 GGUF 포맷 지원**:
  - 1.58비트, Q4_K_M, Q8 등 다양한 비트폭 양자화 GGUF 파일이 배포되어 맥북(Apple Silicon Metal) 및 엔비디아 지포스(RTX 3090/4090) 단일·다중 GPU 환경에서 로컬 실행이 완료 검증되었습니다.
