알리바바 큐원(Qwen) 연구팀이 오픈소스 생태계 전반의 코드 생성 및 리포지토리 단위 추론 역량을 상용 폐쇄형 플래그십 수준으로 끌어올린 코드 특화 모델 **Qwen2.5-Coder-32B-Instruct**를 공식 공개했습니다. 총 5조 5,000억(5.5T) 토큰에 달하는 방대한 소스 코드, 텍스트-코드 그라운딩, 합성 데이터를 바탕으로 사전학습 및 정밀 정렬을 거쳤으며, GPT-4o와 대등한 코딩 성능을 32B 단일 노드 구동 규격에 압축했습니다.

---

### 1. 모델 핵심 아키텍처 및 하드웨어 스펙

* **전체 파라미터**: 32.5B (비임베딩 파라미터: 31.0B)
* **기본 컨텍스트 윈도우**: 최대 131,072 토큰 (128K), 단일 생성 최대 8,192 토큰 지원
* **신경망 구조**:
  * RoPE(Rotary Position Embedding) 및 SwiGLU 활성화 함수 기반 Causal 트랜스포머
  * RMSNorm 및 Attention QKV 편향(bias) 적용
  * 총 64개 레이어
  * GQA(Grouped Query Attention): Query 헤드 40개, Key-Value 헤드 8개 구성으로 장문맥 추론 메모리 점유 최적화
* **라이선스**: Apache 2.0 라이선스 기반 상업적 배포 및 자체 호스팅 허용

---

### 2. 주요 벤치마크 성능 평가

Qwen2.5-Coder-32B-Instruct는 단순 코드 완성을 넘어 실제 코드베이스 리팩터링, 버그 수정(Code Repair), 다단계 에이전트 워크플로 전반에서 오픈 가중치 모델 최고 수준의 지표를 달성했습니다:

* **코드 생성 및 단위 테스트**:
  * **EvalPlus HumanEval+**: 86.6% 기록 (Claude 3.5 Sonnet의 83.5%, GPT-4o의 80.5%를 상회)
  * **LiveCodeBench (Pass@1)**: 40.5% (경쟁 오픈 MoE인 DeepSeek-Coder-V2 236B의 35.8%를 크게 앞섬)
* **코드 수정 및 디버깅 (Code Repair)**:
  * **Aider Benchmark**: 73.7% 달성 (GPT-4o와 대등한 수정 성공률 기록)
  * Aider Diff 포맷 준수율: 94.0% – 94.7%
* **리포지토리 에이전트 및 일반 추론**:
  * **SWE-bench Verified**: 바닐라 세팅 기준 31.0%, 에이전트 스캐폴딩(Scaffolding) 결합 시 최대 61.4% 해결률 달성
  * **MMLU (기초 일반 지식)**: 79.1% 유지 (코딩 특화 파인튜닝 과정에서 발생할 수 있는 일반 추론 능력 저하 방지)

---

### 3. 로컬 구동 및 프레임워크 지원

Qwen 연구팀은 오픈소스 커뮤니티 개발자들이 온프레미스 및 개인 워크스테이션에서 데이터 유출 없이 구동할 수 있도록 공식 배포 규격을 마련했습니다:

* **Ollama 완벽 지원**:
  ```bash
  # 32B Instruct 정밀도 실행 (기본 Q4_K_M 양자화)
  ollama run qwen2.5-coder:32b
  ```
* **llama.cpp 및 GGUF 생태계**:
  * Hugging Face 공식 레포지토리(`Qwen/Qwen2.5-Coder-32B-Instruct-GGUF`)를 통해 Q4_K_M, Q5_K_M, Q8_0 등 다양한 정밀도의 GGUF 파일 제공
  * 단일 24GB VRAM GPU(RTX 3090/4090) 환경에서 4비트 양자화(Q4_K_M) 시 오프로딩을 통해 안정적 구동 가능
* **고성능 서빙 프레임워크**:
  * vLLM, SGLang, LMDeploy에 즉시 배포 가능한 텐서 병렬화 및 PagedAttention 호환 코드 내장
