## 1. 개요

Prism ML 연구팀이 Qwen3.8-27B 아키텍처를 기반으로 3진 가중치(Ternary Weights, 1.72~1.75 bits/weight) 압축 기법을 전면 적용한 차세대 오픈소스 언어 모델 **Ternary-Bonsai-2-27B**의 가중치 및 GGUF 배포본을 허깅페이스(Hugging Face)에 공개했습니다.

기존 4비트 미만 극저비트 양자화(Sub-4-bit Quantization) 환경에서 발생하던 추론 붕괴 문제를 극복하고, 원본 54GB(FP16) 크기의 27B 모델을 단 5.95GB(약 9분의 1) 크기로 축소하면서도 전체 성능의 98.2%를 유지하는 기술적 성과를 달성했습니다. 이에 따라 고가의 서버용 가속기 없이도 일반 소비자용 노트북 및 단일 8GB~12GB VRAM GPU 환경에서 27B급 고성능 추론 및 에이전트 작업이 가능해졌습니다.

## 2. 모델 아키텍처 및 세부 스펙

Ternary-Bonsai-2-27B는 토큰 임베딩, 어텐션 프로젝션, MLP 레이어, 언어 모델 헤드(LM Head) 전반에 걸쳐 하드웨어 친화적인 3진 인코딩을 적용했습니다.

- **기반 모델(Base Model)**: Qwen3.8-27B (Gated-DeltaNet과 Full Attention이 혼합된 64개 레이어의 하이브리드 어텐션 구조)
- **총 파라미터 수**: 약 270억 개 (27B)
- **유효 가중치 비트 수(Effective bpw)**: 1.72 ~ 1.75 bits per weight
- **기본 컨텍스트 윈도우(Context Window)**: 네이티브 262,144 토큰 (262K, 최대 1M 확장 구조 지원)
- **배포 포맷 및 크기**:
  - `PTQ1_0` GGUF: 5.95 GB (3진 트릿을 밀집 패킹한 1.75 bpw 포맷, 메모리가 극도로 제약된 8GB/12GB GPU 및 온디바이스 타깃)
  - `PQ2_0` GGUF: 7.21 GB (2비트 슬롯 배치 포맷으로 디코딩 처리량 극대화)
  - `mmproj-Q8_0`: 0.92 GB (시각 비전 타워 분리 패키지)
- **양자화 방식**: 아다마르(Hadamard) 활성화 변환 및 블록 스케일 보존형 3진 가중치 매핑

## 3. 벤치마크 및 성능 검증

기존 2비트급 양자화 기법(IQ2_XXS 등)은 복잡한 논리 추론이나 코드 생성 시 급격한 성능 저하가 발생했으나, Ternary-Bonsai-2-27B는 FP16 원본 대비 98.2%의 성능 유지율을 기록했습니다.

| **에이전트 도구 호출 (Tool Calling)** | **74.92** | 51.00 | 75.40 |

## 4. 로컬 구동 및 배포 지원

Ternary-Bonsai-2-27B는 패킹된 가중치를 런타임에서 FP16으로 역변환하지 않고 네이티브 3진 연산 커널로 직접 처리합니다.

- **llama.cpp 및 로컬 서버 (Ollama/OpenAI API 호환)**:
  - 전용 아다마르 커널 및 3진 연산 루틴이 포함된 `PrismML-Eng/llama.cpp` 포크를 통해 CUDA 및 Metal 가속 지원
  - 표준 CLI 명령어 및 OpenAI 호환 API 서버 구동:
    ```bash
    llama-server -m Ternary-Bonsai-2-27B-PQ2_0.gguf \
      --mmproj Ternary-Bonsai-2-27B-mmproj-Q8_0.gguf \
      -ngl 99 -c 32768 --host 127.0.0.1 --port 8080
    ```
  - 단일 RTX 3060 12GB 환경에서 약 34 tokens/sec, RTX 5060 Ti 16GB 환경에서 약 37 tokens/sec의 실시간 디코딩 속도 측정
- **Apple Silicon (MLX)**:
  - `prism-ml/Ternary-Bonsai-2-27B-mlx-2bit` 공식 저장소를 통해 M-시리즈 Mac에서 네이티브 통합 메모리 가속 지원
  - 표준 비트 변환 버전(`pipenetwork/Ternary-Bonsai-2-27B-MLX-bf16`)을 활용한 범용 파인튜닝 지원
- **WebGPU 지원**:
  - 브라우저 상에서 클라우드 통신 없이 100% 로컬 클라이언트 메모리로 작동하는 WebGPU 데모 커널 배포 완료

## 5. 결론 및 산업적 시사점

Ternary-Bonsai-2-27B는 대규모 모델의 파라미터 크기와 실제 디바이스 메모리 간의 간극을 3진 가중치 아키텍처로 해결한 대표적 사례입니다. 27B 규모의 프론티어급 복합 추론 모델을 모바일 워크스테이션 및 일반 소비자용 단일 GPU 메모리 규격(6GB~8GB) 내에 안착시킴으로써, 온디바이스 에이전트와 오프라인 인텔리전스 워크플로우의 상용화 범위를 대폭 확장할 것으로 평가받고 있습니다.
