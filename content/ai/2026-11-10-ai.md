중국 AI 연구소 딥시크(DeepSeek)가 복잡한 수학·코드·논리적 사고에서 폐쇄형 최상위 추론 모델(OpenAI o1 수준)과 대등한 성능을 발휘하는 플래그십 오픈 가중치 추론 모델 **DeepSeek-R1**과 기초 연구 버전인 **DeepSeek-R1-Zero**를 허깅페이스(Hugging Face)를 통해 정식 공개했습니다. 

이번 릴리즈는 대규모 지도학습 미세조정(SFT) 없이 그룹 상대 정책 최적화(GRPO, Group Relative Policy Optimization) 기반 순수 강화학습(RL)만으로 복잡한 다단계 생각의 사슬(Chain-of-Thought, CoT), 자기 검증(Self-verification), 오류 반성(Reflection) 등의 고급 추론 능력이 창발될 수 있음을 세계 최초로 증명하고 가중치를 완전 오픈소스로 개방했다는 점에서 AI 연구 생태계에 중대한 이정표를 세웠습니다.

---

### 1. 모델 핵심 스펙 및 아키텍처 특성

- **총 파라미터 수**: 671B (총 6,710억 개 파라미터)
- **활성 파라미터 수 (Active Parameters)**: 토큰당 약 37B (고효율 Mixture-of-Experts, MoE 구조)
- **컨텍스트 윈도우**: 기본 128K (최대 128,000 토큰 지원)
- **학습 파이프라인**:
  - **DeepSeek-R1-Zero**: SFT 콜드스타트 없이 순수 보상 기반 GRPO 대규모 강화학습을 적용하여 자가 추론 패턴 획득.
  - **DeepSeek-R1**: Zero 버전에서 나타난 언어 혼용 및 끝없는 반복 문제를 해결하기 위해, 소량의 고품질 콜드스타트 데이터를 투입한 후 다단계 RL 및 거부 샘플링 기반 SFT를 결합해 가독성과 인간 선호도를 극대화.
- **증류(Distillation) 오픈 라인업**:
  - 연구진은 R1에서 생성된 80만 개의 고난도 추론 데이터를 기반으로 소형 오픈 모델에 지식을 증류한 소형 모델군(DeepSeek-R1-Distill-Qwen-1.5B / 7B / 14B / 32B 및 DeepSeek-R1-Distill-Llama-8B / 70B)을 함께 배포.
- **라이선스**: MIT License (연구 및 상업적 목적 모두 무상 활용 가능)

### 2. 주요 벤치마크 평가 결과

DeepSeek-R1은 수학, 코딩, 복잡한 과학 추론 등 고난도 벤치마크 전반에서 기존 플래그십 모델들을 압도하며 OpenAI o1-1217과 직접 경쟁하는 결과를 기록했습니다.

| 벤치마크 (평가 영역) | DeepSeek-R1 | OpenAI o1-1217 | DeepSeek-V3 |
| :--- | :---: | :---: | :---: |
| **AIME 2024** (경시대회급 수학, Pass@1) | **79.8%** | 79.2% | 39.2% |
| **MATH-500** (대학·올림피아드 수학 전수 평가) | **97.3%** | 96.4% | 90.2% |
| **GPQA Diamond** (박사 수준 고난도 과학 추론) | **71.5%** | 75.7% | 59.1% |
| **MMLU** (종합 학술 지식 및 문제 해결) | **90.8%** | 91.8% | 88.5% |
| **MMLU-Pro** (확장 심화 학술 평가) | **84.0%** | 89.1% | 75.9% |
| **Codeforces** (알고리즘 코딩, Elo 레이팅) | **2,029 (상위 96.3%)** | 2,060 (상위 96.6%) | 1,489 (상위 58.7%) |
| **SWE-bench Verified** (소프트웨어 엔지니어링) | **49.2%** | 48.9% | 42.0% |

- 수학 올림피아드 수준의 고난도 문제(MATH-500)에서 97.3%의 정답률을 기록하며 현존 오픈 모델 중 최고점을 달성했습니다.
- 알고리즘 경진대회 플랫폼 Codeforces에서 Elo 2,029를 기록하여 인간 상위 3.7% 이내의 전문 경쟁 프로그래머 수준에 도달했습니다.

### 3. 로컬 환경 구동 및 배포 지원

- **Ollama 공식 라이브러리 등록**:
  - 발표 즉시 Ollama 공식 레지스트리에 등재되었으며, 단일 CLI 명령어로 모델 다운로드 및 실행이 가능합니다.
  - 풀버전 구동: `ollama run deepseek-r1`
  - 단일 GPU 및 개인 PC(MacBook Pro, RTX 3090/4090 등)를 위한 고효율 증류 모델 구동:
    - `ollama run deepseek-r1:1.5b`
    - `ollama run deepseek-r1:8b`
    - `ollama run deepseek-r1:14b`
    - `ollama run deepseek-r1:32b`
    - `ollama run deepseek-r1:70b`
- **추론 서빙 프레임워크 지원**:
  - vLLM, SGLang, TensorRT-LLM, LM Studio, llama.cpp(GGUF 포맷)에서 완전 지원됩니다.
  - 출력 토큰 제어 시 추론 토큰(Thinking tokens)과 최종 답변 토큰이 분리되어 렌더링되며, 시스템 프롬프트 없이 온전한 사용자 프롬프트 기반으로 Temperature 0.6 환경에서 가장 안정적인 성능을 발휘하도록 권장됩니다.
