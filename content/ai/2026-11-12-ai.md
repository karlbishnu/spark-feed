마이크로소프트(Microsoft)가 복합 추론, 수학, 코딩 영역에서 70B급 대형 언어 모델에 필적하는 고효율 오픈소스 소형 언어 모델(SLM) **'Phi-4 (14B)'**를 정식 공개하고 가중치를 오픈소스로 배포했습니다.

Phi-4는 파라미터 크기 대비 극한의 지능 밀도를 목표로 설계되었으며, MIT 라이선스를 채택해 상용화 및 연구 목적의 자유로운 활용이 가능합니다.

---

### 1. 모델 주요 사양 (Specifications)

- **개발사**: 마이크로소프트 리서치 (Microsoft Research)
- **파라미터 크기**: 140억 개 (14B dense decoder-only Transformer)
- **컨텍스트 윈도우**: 기본 16,384 토큰 (16K context window)
- **사전 학습 데이터 토큰**: 약 9조 8,000억 개 (9.8T tokens)
- **학습 인프라**: 1,920장의 NVIDIA H100 80GB GPU 클러스터 (21일 소요)
- **라이선스**: MIT License (상업적 이용 및 수정 배포 완전 허용)

---

### 2. 벤치마크 평가 성능

Phi-4는 합성 데이터(Synthetic Data) 품질 극대화와 정교한 커리큘럼 학습을 통해 14B 규모임에도 불구하고 대형 모델(Llama-3.3-70B, GPT-4o-mini 등)과 맞먹는 추론 벤치마크 결과를 기록했습니다.

- **MMLU (다분야 학술 지식 이해, 5-shot)**: **84.8%**
- **MATH (경시대회 수준 고난도 수학 추론)**: **80.4%**
- **HumanEval (파이썬 코드 생성)**: **82.6%**
- **GPQA (대학원 수준 과학 추론, Diamond)**: **56.1%**
- **GSM8K (초·중등 수학 추론)**: **90% 이상** (기존 동일 체급 SLM 대비 압도적 격차)

특히 경시대회 수학 벤치마크인 MATH 80.4%와 MMLU 84.8%는 단일 GPU(24GB VRAM급 소비 전력/메모리) 환경에서 구동 가능한 14B 모델 중 최고 수준의 성능 밀도를 입증합니다.

---

### 3. 고품질 합성 데이터 중심 학습 아키텍처

Phi-4는 단순히 웹 크롤링 데이터를 대규모로 투입하는 기존 방식을 탈피하고 데이터의 ‘추론 밀도’에 집중했습니다:

1. **합성 교과서 데이터(Synthetic Textbook-like Data)**: 고성능 프론티어 모델(GPT-4o 등)을 활용해 엄격하게 검증된 수학 문제 해결 과정, 단계별 논리 전개, 고품질 알고리즘 코드를 생성하여 사전 학습에 투입했습니다.
2. **다단계 정렬 및 사후 학습(Post-training)**: 지도 미세조정(SFT)뿐 아니라 직접 선호도 최적화(DPO) 및 인간 피드백 기반 강화학습(RLHF)을 결합하여 환각 현상을 억제하고 지시 이행 충실도(Instruction Following)를 대폭 개선했습니다.
3. **중간 학습(Mid-training) 컨텍스트 확장**: 4K 토큰 기반의 1차 학습 후, 긴 문맥 처리 안정성을 위해 데이터 혼합비를 재조정하며 16K 토큰 윈도우로 확장 학습을 완료했습니다.

### 4. 로컬 구동 및 인프라 지원 (Local Deployment)

Phi-4는 경량화된 구조 덕분에 양자화(Quantization) 시 일반 사용자용 데스크톱 및 엣지 환경에서 단일 GPU로 완전 구동이 가능합니다.

- **Ollama 공식 지원**: CLI 환경에서 명령어 한 줄로 즉시 로컬 실행이 가능합니다.
  ```bash
  ollama run phi4
  ```
- **llama.cpp / GGUF**: Q4_K_M 양자화 적용 시 8~10GB 수준의 VRAM 환경(RTX 3060, RTX 4060 Ti 등)에서도 쾌적한 추론 속도를 보장합니다.
- **vLLM 및 SGLang 서빙**: 배치 추론 및 고처리량 엔터프라이즈 API 서빙 프레임워크와 완벽 호환됩니다.
- **Hugging Face Transformers**:
  ```python
  import torch
  from transformers import AutoModelForCausalLM, AutoTokenizer

  model_id = "microsoft/phi-4"
  tokenizer = AutoTokenizer.from_pretrained(model_id)
  model = AutoModelForCausalLM.from_pretrained(
      model_id,
      device_map="auto",
      torch_dtype=torch.bfloat16,
      trust_remote_code=True
  )

  prompt = "수학적 귀납법을 사용하여 모든 자연수 n에 대해 1부터 n까지의 합 공식을 증명하세요."
  inputs = tokenizer(prompt, return_tensors="pt").to(model.device)
  outputs = model.generate(**inputs, max_new_tokens=512)
  print(tokenizer.decode(outputs[0], skip_special_tokens=True))
