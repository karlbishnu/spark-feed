## 1. 개요 및 주요 특징

알리바바의 Qwen 팀이 차세대 비전-언어 멀티모달 플래그십 모델인 **Qwen2.5-VL-72B-Instruct**를 오픈소스로 공개했습니다. 이번 모델은 이전 세대인 Qwen2-VL을 전면 개선하여 문서 이해, 다이어그램 분석, 긴 영상 추론, GUI 기반 에이전트(Agentic AI) 기능에서 오픈소스 모델 중 최고 수준의 성능을 구현했습니다.

특히 동적 해상도(Dynamic Resolution)를 비디오의 시간 축(Temporal Dimension)으로 확장 적용하고 다중 모달 로터리 위치 임베딩(mRoPE)을 개선하여, 1시간 이상의 장기 영상 속 특정 이벤트를 정확한 타임스탬프로 찾아내는 세분화된 인지 능력을 갖추었습니다. 또한 바운딩 박스와 좌표 포인트 기반의 시각적 로컬라이제이션(Visual Localization) 및 정형화된 JSON 출력 기능을 기본 제공합니다.

## 2. 모델 핵심 사양 (Model Specifications)

- **개발사**: 알리바바 첸원(Qwen) 연구팀
- **총 파라미터 수**: 약 72.7B (720억 개)
- **지원 컨텍스트 길이**: 최대 128,000 토큰 (128K)
- **지원 입력 모달리티**: 텍스트, 이미지(임의 해상도 및 화면비율), 비디오(초당 프레임 가변 샘플링 지원)
- **비전 인코더 아키텍처**: 윈도우 어텐션(Window Attention)이 통합된 초경량 고효율 ViT 구조
- **라이선스**: Qwen 오픈 라이선스 (연구 및 상용 서비스 배포 가능)

## 4. 로컬 구동 및 온프레미스 배포 환경 지원

사용자는 오픈소스 생태계 전반의 추론 엔진 및 로컬 프레임워크를 통해 별도의 API 의존 없이 온프레미스 및 로컬 머신에서 해당 모델을 직접 실행할 수 있습니다.

### Ollama 지원
Ollama 공식 모델 라이브러리에 `qwen2.5vl:72b`로 등록되어 간단한 CLI 명령으로 실행할 수 있습니다:

```bash
ollama run qwen2.5vl:72b
```

### 서빙 및 최적화 엔진
- **vLLM**: Tensor Parallelism(TP) 모드 및 멀티모달 데이터 병렬 서빙을 공식 지원하여 대규모 프로덕션 엔드포인트 구축이 가능합니다.
- **GGUF / llama.cpp**: Q4_K_M, Q8_0 등 4비트 및 8비트 양자화 가중치가 공개되어 단일 워크스테이션 환경에서도 VRAM 점유를 최소화하여 구동할 수 있습니다.
