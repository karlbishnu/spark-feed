알리바바 클라우드의 Qwen 팀이 차세대 오픈소스 멀티모달 비전-언어 모델(VLM) 플래그십인 **Qwen2.5-VL-72B-Instruct**를 허깅페이스(Hugging Face)와 모델스코프(ModelScope)를 통해 전면 공개했습니다. 

이번 릴리즈는 이전 세대인 Qwen2-VL 대비 복합 문서 분석, 세밀한 객체 위치 추정(Grounding), 1시간 이상의 장기 영상 이해 및 에이전트 인터랙션 능력을 획기적으로 향상시켰으며, 상용 독점 모델인 GPT-4o 및 Claude 3.5 Sonnet과 대등하거나 일부 문서 이해 영역에서 이를 능가하는 성적을 기록했습니다.

### 1. 모델 스펙 및 아키텍처 특징

- **파라미터 수**: 총 약 72B (727억 개 파라미터)
- **컨텍스트 윈도우**: 최대 128,000 토큰(128K) 지원 (장기 영상 및 대용량 문서 배치 처리 최적화)
- **네이티브 동적 해상도(Dynamic Resolution) ViT**: 원본 이미지의 비율과 해상도를 왜곡 없이 동적 패치로 처리하며, ViT 인코더에 윈도우 어텐션(Window Attention)을 적용해 연산 오버헤드를 대폭 경감.
- **업그레이드된 mRoPE(Multimodal Rotary Position Embedding)**: 1차원 텍스트, 2차원 공간 이미지, 3차원 시간 영상 정보를 통합적으로 표현하며, 비디오의 절대 시간 정렬 메커니즘을 지원해 초 단위의 정밀한 이벤트 탐색(Event Localization)이 가능.
- **구조화된 출력 및 시각적 바운딩 박스**: 인보이스, 표, 양식 이미지로부터 정형화된 JSON 및 HTML(QwenVL-HTML) 태그 출력을 안정적으로 생성.

### 4. 로컬 구동 환경 및 배포 지원 (Ollama 지원)

Qwen2.5-VL-72B-Instruct는 다양한 오픈소스 런타임 생태계와 즉시 연동됩니다.

- **Ollama 공식 지원**:
  Ollama 0.7.0 이상 환경에서 별도의 수동 변환 없이 단일 CLI 명령어로 로컬 인퍼런스를 시작할 수 있습니다.
  ```bash
  # Ollama를 통한 72B 모델 구동 (양자화 버전 자동 로드)
  ollama run qwen2.5vl:72b
  ```
  *(참고: 경량화된 엔드포인트 구축 시 7B 및 3B 파라미터 모델인 `qwen2.5vl:7b`, `qwen2.5vl:3b`도 선택 가능합니다.)*

- **vLLM 및 SGLang 고속 서빙**:
  고처리량 배포 환경을 위해 Tensor Parallelism(TP)과 FlashAttention 최적화, AWQ 양자화 가중치(`Qwen2.5-VL-72B-Instruct-AWQ`) 서빙을 완벽히 지원합니다.
  ```bash
  vllm serve Qwen/Qwen2.5-VL-72B-Instruct \
      --tensor-parallel-size 4 \
      --max-model-len 32768 \
      --trust-remote-code
  ```

Qwen2.5-VL-72B-Instruct의 모델 가중치와 사용 예제 코드는 Hugging Face 공식 레포지토리(`Qwen/Qwen2.5-VL-72B-Instruct`)에서 확인할 수 있습니다.
