OpenBMB가 온디바이스 및 로컬 에지 환경에 최적화된 차세대 초경량 오픈소스 언어 모델인 **MiniCPM5-2B**를 공식 공개하고 모델 가중치와 학습 데이터 세트를 전면 배포했습니다.

MiniCPM5-2B는 3B 미만의 초소형 크기에도 불구하고 고급 코딩, 다단계 에이전트 도구 호출(Tool Calling), 심층 추론 기능을 단일 체크포인트로 통합하여 온디바이스 AI의 성능 한계를 대폭 끌어올렸습니다.

---

### 1. 모델 핵심 아키텍처 및 스펙

* **총 파라미터 수**: 약 2.52B (임베딩 레이어 제외 시 실질 연산 파라미터 약 1.98B)
* **기반 구조**: 표준 Llama 구조 기반 Causal LM (LlamaForCausalLM)
* **컨텍스트 윈도우**: 네이티브 131,072 토큰 (128K) 지원
* **하이브리드 추론 모드 (Think / No-Think)**: 단일 가중치 내에서 즉각적인 응답 모드와 테스트 타임 연산을 확장하는 심층 추론 모드를 유연하게 전환
* **학습 방식 및 오픈 데이터**: 에이전트 전문 교사 모델 5종을 포함한 총 16개 전문가 모델을 통한 온폴리시 지식 증류(On-policy Distillation) 적용. 50만 건의 에이전트 SFT 데이터와 8만 건 이상의 강화학습 데이터(`UltraData-SFT-Agent-2609`, `UltraData-RL-2609`) 동시 공개
* **추측 디코딩 전용 드래프트 모델**: 추론 처리 속도 극대화를 위해 323M 크기의 전용 드래프트 체크포인트인 `MiniCPM5-2B-DSpark` 제공

---

### 2. 주요 벤치마크 평가 결과

MiniCPM5-2B는 동급 파라미터(2B~4B급) 모델들을 큰 격차로 상회하며 초소형 모델 분야에서 최고 수준(SOTA)의 성능을 달성했습니다.

* **Artificial Analysis Intelligence Index v4.2**: **15점** (4B 파라미터 미만 오픈 가중치 모델군 중 1위 기록)
* **수학 및 심층 추론 (AIME 2026)**: **86.5점**
* **코드 생성 (LiveCodeBench v6)**: **69.1점**
* **실제 소프트웨어 이슈 해결 (SWE-bench Verified)**: **46.4%** 해결율 달성
* **종합 비교 벤치마크 세트**: 평균 **53.9점**을 기록하여 주요 2B급 모델군(Qwen3.5-2B, LFM2.5-2.6B, Gemma-4-E2B-it)뿐만 아니라 다수의 4B급 모델을 상회

---

### 3. 로컬 구동 및 프레임워크 지원 여부

MiniCPM5-2B는 발표 직후 주요 로컬 추론 런타임 및 경량화 생태계에 완벽히 통합되었습니다.

* **Ollama 공식 지원**: 별도의 커스텀 빌드 없이 공식 최신 런타임에서 기본 실행 가능.
  * 일반 실행: `ollama run openbmb/minicpm5-2b`
  * 심층 추론 모드 구동: `ollama run openbmb/minicpm5-2b --think`
* **GGUF 및 Llama.cpp**: 4비트 양자화(`Q4_K_M`) 기준 가중치 파일 크기가 약 1.6GB에 불과해 8GB VRAM 이하의 보급형 GPU 및 일반 랩톱 환경에서 초당 140토큰 이상의 고속 추론 가능
* **서빙 프레임워크 지원**: vLLM(0.21.0 이상 버전에서 네이티브 도구 파서 지원), SGLang, Apple Silicon 전용 MLX 포맷 지원
* **웹 브라우저 로컬 구동**: ONNX Runtime 및 Transformers.js를 통해 클라우드 서버 없이 로컬 WebGPU 환경에서 완전 오프라인 파일 분석 및 Bash 툴 제어 데모 실행 지원
