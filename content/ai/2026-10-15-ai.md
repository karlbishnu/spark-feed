## 1. 개요 및 릴리즈 핵심

MIT 분사 인공지능 연구 기업 리퀴드 AI(Liquid AI)가 자사의 플래그십 경량 혼합 전문가(MoE) 모델인 **'LFM2.5-24B-A2B'**를 오픈 가중치로 정식 공개했습니다. LFM2.5 시리즈의 최상위 모델인 이번 릴리즈는 총 240억 개(24.0B) 파라미터 중 토큰당 약 24.5억 개(2.45B)만 선별적으로 활성화하는 고효율 MoE 설계를 채택했습니다. 

기존 온디바이스 언어 모델들이 겪던 복합 추론 및 에이전트 도구 호출(Tool Calling) 성능의 한계를 극복하기 위해, 모든 입력에 대해 체계적인 사고 과정(Chain of Thought)을 선행하는 전용 추론 아키텍처를 도입했으며, 허깅페이스(Hugging Face)를 통해 기본 베이스 가중치와 사후 학습 가중치가 모두 무료 배포되었습니다.

## 2. 모델 아키텍처 및 핵심 스펙

LFM2.5-24B-A2B는 전통적인 트랜스포머 구조의 연산 병목을 해결하기 위해 게이트 단기 합성곱(Gated Short Convolution)과 그룹 쿼리 어텐션(GQA)을 결합한 하이브리드 신경망을 기반으로 구축되었습니다.

```
               [입력 프롬프트 / 131K 컨텍스트]
                              │
                              ▼
        ┌───────────────────────────────────────────┐
        │  40 Layers Hybrid Backbone                │
        │  - 30x Double-Gated Short Conv Blocks     │
        │  - 10x Grouped-Query Attention (GQA)      │
        └───────────────────────────────────────────┘
                              │
                              ▼
        ┌───────────────────────────────────────────┐
        │  Mixture-of-Experts (MoE) Routing         │
        │  - 총 64 Experts (블록당)                  │
        │  - Top-4 Routing (토큰당 2.45B만 활성화)    │
        └───────────────────────────────────────────┘
                              │
                              ▼
             [<think> 추론 블록 + 고속 에이전트 응답]
```

### 상세 사양 제원

* **총 파라미터(Total Parameters)**: 24.0B (240억 개)
* **활성화 파라미터(Active Parameters)**: 토큰당 약 2.45B (24.5억 개)
* **컨텍스트 윈도우(Context Length)**: 131,072 토큰 (131K)
* **신경망 레이어 구성**: 총 40개 계층 (30개 게이트 단기 합성곱 블록 + 10개 GQA 어텐션 블록)
* **전문가(Expert) 토폴로지**: 레이어당 64개 전문가 중 상위 4개(Top-4) 동적 라우팅
* **토크나이저 어휘 사전**: 128,000 토큰 (비라틴 문자 및 한국어, 다국어 처리 효율 개선)
* **학습 토큰 규모**: 총 36조(36T) 토큰 (사전학습 33T + 중기 롱컨텍스트·추론 강화 3T)
* **지원 언어**: 한국어, 영어, 프랑스어, 독일어, 스페인어, 중국어, 일본어, 아랍어 등 16개 언어
* **라이선스**: LFM 오픈 커뮤니티 라이선스 1.0 (상업적 활용 및 로컬 배포 지원)

## 3. 벤치마크 성능 평가

LFM2.5-24B-A2B는 온디바이스 에이전트 자율 수행과 도구 조작 환경(OpenClaw, Hermes Agent, Pi 등)에서 진행된 직접 강화학습(Agentic RL)의 효과로 경쟁 모델 대비 뛰어난 성능을 기록했습니다. 특히 파라미터 수가 50%가량 더 큰 Qwen3.6-35B-A3B와의 비교에서도 에이전트 실무 성능 지표에서 우위를 보였습니다.

| 평가 벤치마크 | LFM2.5-24B-A2B (2.45B 활성) | Qwen3.6-35B-A3B (3.5B 활성) | 비고 |
| :--- | :---: | :---: | :--- |
| **LiveClaw (도구 사용·에이전트)** | **48.09** | 38.19 | +25.9% 자율 에이전트 수행 격차 |
| **IFBench (복합 지시 준수)** | **74.69** | 64.21 | 엄격한 제약조건 추종 정확도 |
| **GPQA Diamond (심층 과학 추론)** | 74.42 | 83.69 | 전문가 수준 지식 회상 |
| **SWE-Bench Verified (코딩 해결)** | 51.00 | 66.20 | 자율 버그 패치 및 코드 생성 |
| **AutomationBench (자동화 에이전트)**| **최고 등급 (1위)** | 기준점 대비 열세 | 차세대 GUI/CLI 도구 조작 평가 |

*참고: 모델의 경량 활성화 구조 특성상 암기식 지식 질의(GPQA)보다는 실시간 웹 검색 및 도구 호출(Tool Calling/RAG)과 연계할 때 성능이 극대화되도록 최적화되어 있습니다.*

## 4. 로컬 구동 및 런타임 환경 지원

토큰당 연산 부하가 2.45B 수준에 불과하므로, 고사양 데이터센터 GPU뿐만 아니라 일반 랩톱과 엣지 장비에서도 높은 초당 생성 토큰 수(TPS)를 달성합니다.

* **추론 속도 지표**:
  * Apple Silicon M5 Max 단일 칩 환경: 약 184 tok/s 달성
  * 엔비디아 싱글 B300 GPU 환경: 최대 21,000 tok/s 처리
* **Ollama 및 llama.cpp 지원**:
  * 커뮤니티 전용 GGUF 가중치(`LiquidAI/LFM2.5-24B-A2B-GGUF`) 및 QAD 양자화 파일이 공식 배포되었습니다.
  * 양자화 손실을 최소화한 Q4_0, Q8_0 체크포인트를 통해 16GB 이하 VRAM을 탑재한 로컬 PC에서도 여유롭게 구동할 수 있습니다.
  * 구동 예시:
    ```bash
    ollama run hf.co/LiquidAI/LFM2.5-24B-A2B-GGUF
    ```
* **MLX 및 ONNX 지원**:
  * Apple Silicon을 위한 MLX 정수 양자화(4-bit, 5-bit, 6-bit, 8-bit)와 엣지 임베디드를 위한 ONNX 런타임 변환 모델이 제공됩니다.
* **서버 서빙 지원**:
  * `vLLM` 및 `SGLang`의 FP8 블록 양자화(`LFM2.5-24B-A2B-FP8`)를 기본 지원하여 고성능 다중 사용자 에이전트 서버 구축이 가능합니다.

## 5. 종합 평가

LFM2.5-24B-A2B는 단순한 매개변수 확장 경쟁에서 벗어나 하이브리드 어텐션 구조와 초고효율 MoE 라우팅을 통해 실제 사용자 장치에서 실시간으로 자율 작업을 실행할 수 있는 차세대 에이전트 모델의 기준을 제시했습니다. 2B급 모델의 가벼운 추론 속도와 24B급 모델의 표현력을 결합하여, 향후 독립형 로컬 에이전트 및 프라이빗 워크플로 구축에 핵심적인 오픈소스 대안이 될 것으로 기대됩니다.
